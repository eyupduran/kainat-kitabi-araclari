Privacy Policy

Kainat Kitabi Araclari · Last updated: 26 October 2026

Kainat Kitabi Araclari ("the tool") is a private command-line tool that runs on the channel owner's own computer and uses YouTube API Services to publish the owner's own videos to the owner's own YouTube channel. This policy explains what data the tool accesses and what it does with it.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

With the Google account owner's permission (OAuth), the tool accesses only the owner's own YouTube channel:

  • basic channel information (channel name and ID, subscriber, video and view counts), to confirm that the correct channel is connected;
  • the owner's own videos, thumbnails, subtitles, playlists and the owner's own comments, in order to upload and organise them;
  • YouTube Analytics reports for the owner's own channel (for example views and watch time per video).

The tool does not access, collect or store personal data of viewers, commenters or any other YouTube user.

How the data is used

The data is used only to publish and organise the owner's videos and to show the owner reports about their own channel. It is not used for advertising, profiling or any other purpose.

Storage

The tool has no server and no database. The OAuth refresh token is stored only as a local file on the owner's computer. After an upload, the address of the owner's new video is written to a local note on the same computer. Analytics reports are shown on the owner's screen and are not stored. Nothing is sent to any party other than Google's own APIs.

Sharing

The tool does not sell, share or transfer any data to third parties.

Cookies

The tool does not use cookies or similar technologies. These information pages do not set cookies and contain no tracking.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After revocation the stored token no longer works. The owner can delete the local token and notes at any time; on request sent to the address below, all locally stored data is deleted within 7 days. Apart from the token and the owner's own video addresses, no data obtained from the YouTube API is kept.

Changes

If the tool's use of data changes, this page is updated and the date above changes.
